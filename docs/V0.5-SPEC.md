## Practice Presets

- Store names and unit arrays in config.xml. Existing configs with no presets
  continue using their existing single-unit or multi-unit selection.
- A preset only changes the practice scope, not the study or question mode.
- Empty unit arrays explicitly represent all units. A named missing unit stays
  selected as unavailable; never silently expand it to the whole library.
- Work on a deep copy inside settings. Closing without Save and Close discards
  preset edits and scope changes together.
- New names must be nonempty, at most 60 characters and unique ignoring case.
- Applying a preset loads checkboxes. Editing checkboxes switches to a custom
  selection without modifying the saved preset.
- Updating or renaming an existing preset preserves its place in the list.
- Deleting a preset leaves the current checked units unchanged.
- All persistence uses the existing atomic config save path and backups.

## Verification

Use build.bat -RunTests for model, XML round trips, cancellation, apply/rename/
delete and sampling scope tests. Render the settings form at normal and compact
heights. Desktop input tests remain opt-in through -IncludeDesktopTests.

Do not add dependencies, change XML word/review schemas, migrate user data, or
publish v0.5 until the remaining modules and compatibility tests are complete.
