# v0.6 Learning Content

## Acceptance Contract

- Manual Japanese speech only: toolbar, context menu and F7. Prefer kana;
  never read Chinese. Voice and rate are saved only with settings confirmation.
- Stop speech on next/previous/undo, dialog opening, either hide operation and
  exit. Missing Japanese voices produce an actionable message, not a download.
- Editable Japanese/Chinese examples and source label; lossless XML import,
  export and preview. Default duplicate handling remains skip. Explicit XML
  updates match SourceId and never replace identities or review progress.
- Schema 2 migration preserves IDs, four direction states and review events.
  Save a permanent byte-identical pre-v0.6 backup before migration. Newer
  schemas are rejected. Downgrade requires restoring the pre-upgrade backup.
- Statistics follow the selected units and direction. Today's count is rating
  events in the local calendar day, excluding undo. Due count includes new
  words, excludes missing-kana cards in reading modes. Weak words use active
  direction difficulty >= 6 or errors, with streak < 3; marked words also appear.
- Statistics use existing events only, never fabricate historical activity.
  Deleted words remain counted by event unit snapshots. No FSRS change yet.
- Verify pure logic, migration/import round trips, compact/normal WPF renders,
  native clicks/global hiding and real Japanese synthesis to a silent WAV.
